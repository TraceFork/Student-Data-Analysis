4. Graph and Plot Creation

Gender Distribution

pie(
  gender_count,
  main = "Gender Distribution",
  labels = paste(names(gender_count), gender_count)
)

The pie chart shows the distribution of students according to gender. The size of each section represents the number of students in that category.

Course Distribution

barplot(
  course_count,
  main = "Student Distribution by Course",
  xlab = "Course",
  ylab = "Number of Students",
  las = 2
)

The bar plot compares the number of students across different courses.

Student CGPA

hist(

The histogram displays the distribution of CGPA values.

5. Course-wise CGPA Analysis

course_cgpa <- aggregate(
  CGPA ~ Course,
  data = student_data,
  FUN = mean
)

kable(course_cgpa)
Course CGPA
B.Com 7.794762
B.Sc 6.885833
B.Tech 7.246000
BBA 7.405217
BCA 7.695172

The aggregate function calculates the average CGPA for each course.

Average CGPA by Course

barplot(
  course_cgpa$CGPA,
  names.arg = course_cgpa$Course,
  main = "Average CGPA by Course",
  xlab = "Course",
  ylab = "Average CGPA",
  las = 2
)

The bar plot compares the average CGPA among different courses.
